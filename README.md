**10 Februari 2026**<br>
Belajar kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang software (Progres 38%)<br>

-Belajar Perencanaan Modifikasi Aplikasi dengan Spesifikasi Kebutuhan Perangkat Lunak (SKPL)<br>
-Belajar Penyelesaian Masalah Menggunakan Cara Berfikir Komputasional<br>

**11 Februari 2026**<br>
Belajar kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang software (Progres 82%)<br>
-Belajar tentang Flowchart seperti simbol-simbol, jenis-jenis flowchart dan fungsinya<br>
-Belajar tentang Konsep Dasar Pemrograman simulai dari sintaksis, case sensitive, statement, keyword, pseudocode, variabel dan whitespace<br>
